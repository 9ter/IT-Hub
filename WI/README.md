ผู้จัดทำ ผู้ทบทวน ผู้อนุมัติ ตำแหน่ง วันที่ลงนาม และวันที่มีผลบังคับใช้เว้นว่างไว้สำหรับการควบคุมเอกสารของหน่วยงาน ภาพทั้งหมดใช้ข้อมูลตัวอย่าง ไม่ใช่หลักฐานใบงานจริง

ขั้นตอน Import Excel และตรวจหมายเลขทะเบียนซ้ำทบทวนจากโค้ดปัจจุบันวันที่ 29 ตุลาคม 2569 การปรับ WI ครั้งนี้เป็นงานเอกสาร ไม่ได้รันทดสอบระบบซ้ำหรือแก้ใบงาน ฐานข้อมูล การเชื่อมต่อ NAS หรือ deploy เว็บ รายงานและผลทดสอบวันที่ 28 ตุลาคมคงไว้เป็นหลักฐานของรอบเดิม โดยเฉพาะ `test-results.json`, `browser-results.json`, `health.json`, `lint.json` และ `print-layout.json` เป็นข้อมูลประวัติ ไม่ใช่ผลการตรวจ Word ฉบับนี้

ปรับข้อความที่ JSON แล้วสร้าง Word/Markdown โดยใช้ Python 3 standard library และแม่แบบเดิม:

```bash
python3 WI/tools/build_wi.py
# ระบุแม่แบบต่างตำแหน่งได้:
python3 WI/tools/build_wi.py --template '/path/to/WI-IT-002 E-Procurement.docx'
```

สร้าง PDF จาก Word ด้วย Microsoft Word หรือ LibreOffice ที่ติดตั้งฟอนต์ TH Sarabun New ครบปกติ/ตัวหนา/ตัวเอียง:

```bash
LIBREOFFICE_BIN=/path/to/soffice node WI/tools/print_wi.cjs
python3 WI/tools/check_artifacts.py
```

ตรวจการแบ่งหน้าและสารบัญหลังปรับข้อความทุกครั้ง ไฟล์ `validation/word-build.json` เป็นแผนแบ่งหน้า ส่วน `validation/word-layout.json` เป็นผลตรวจ PDF ที่สร้างจริง แม่แบบต้นฉบับต้องอยู่ตามพาธที่ระบุเมื่อสร้างใหม่ PDF ฉบับนี้ตรวจโดยใช้ LibreOffice 26.2 และฟอนต์ TH Sarabun New ตามแม่แบบ

ชุด ZIP ปัจจุบันใช้ชื่อ `IT-Hub-WI-Rev00-2026-10-29.zip` รวม Word/PDF ต้นฉบับข้อมูล ภาพ เครื่องมือ และรายงานเดิม HTML รูปแบบเดิมและ ZIP วันที่28นำออกจากชุดปัจจุบันแล้ว โดยสำรองฉบับก่อนแก้นอกโครงการไว้

ฟอนต์ Noto Sans Thai ใน `fonts/` ใช้ SIL Open Font License และเป็นทรัพยากรของรายงานเดิม ดู `OFL.txt` ส่วน Word ใช้ TH Sarabun New ตามแม่แบบ โลโก้และภาพหน้าจอมาจาก IT Hub ของโครงการ
