การปรับเอกสาร: แก้ Markdown แล้วสร้าง HTML ใหม่ด้วย Python 3 (standard library เท่านั้น):

```bash
python3 WI/tools/build_wi.py
```

สร้าง PDF โดยเปิด HTML และพิมพ์เป็น A4 หรือใช้สคริปต์ที่ตรวจ layout พร้อม Playwright/Chromium ที่ติดตั้งไว้อยู่แล้ว กำหนดพาธตามเครื่องโดยไม่ต้องติดตั้งเข้าโปรเจกต์ frontend:

```bash
PLAYWRIGHT_MODULE=/path/to/playwright \
CHROMIUM_EXECUTABLE=/path/to/chrome \
node WI/tools/print_wi.cjs
```

สคริปต์สร้างเอกสารไม่เรียก API หรือเชื่อมต่อ NAS และบล็อก HTTP/HTTPS ขณะพิมพ์ ข้อมูล validation เป็นผลตรวจ ณ วันจัดทำ ไม่อัปเดตตามการแก้ Markdown โดยอัตโนมัติ ต้องตรวจและสร้าง manifest ใหม่เมื่อเปลี่ยนไฟล์ส่งมอบ
